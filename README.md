# CommitFlow

AI-powered automation tool for executing atomic commit plans.

## Overview

CommitFlow receives a structured commit plan and executes it automatically on a target repository. It leverages dual AI agents (DeepSeek for code generation and Gemini for code review) to implement changes, enforces quality gates (formatting, type checking), and commits each change atomically.
